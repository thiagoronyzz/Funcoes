## Resultado: SIM — 810 experiências com identidade própria

### Verificação por tipo de interface (amostra aleatória de 12 sites)
1. Simulador Orbital de Gravidade — interface de laboratório (canvas + slider de parâmetro, tema verde-escuro, gráfico de onda sinusoidal)
2. Visualizador 3D de Funções — interface de visualizador científico (gráfico 3D, tema roxo, canvas de função)
3. Torre de Hanoi 3D — interface de jogo de lógica (grade 4x4, células clicáveis, tema roxo, botão reiniciar)
4. Editor de Expressões Matemáticas — interface de editor (textarea grande, toolbar, tema âmbar, fonte mono)
5. Calculadora de IMC Avançada — interface de calculadora (card escuro, input numérico, botão calcular, tema ciano)
6. Laboratório Virtual de Química — interface de experimento (estágio visual, botão executar, tema verde-claro)
7. Gerador de Paletas de Cores — interface de design (swatches de cores, tema rosa, visual artístico)
8. Sintetizador Visual de Ondas — interface de áudio (ondas animadas, tema roxo-escuro, animação CSS)
9. Rede Social de Ideias — interface de colaboração (editor de texto, tema neutro, funcionalidade de compartilhamento)
10. Experimento de Queda Livre — interface de experimento científico (estágio, botão, tema verde)
11. Calculadora de Taxa de Juros — interface de ferramenta financeira (card, input, resultado numérico, tema ciano)
12. Jogo de Memória Dinâmico — interface de jogo (grade interativa, tema roxo, interação por clique)

### Nenhum duplicado funcional encontrado
- Nenhum grupo de 10+ sites resolve exatamente o mesmo problema com a mesma interação.
- Os simuladores têm gráficos dinâmicos e sliders; os cálculos têm input numérico; os jogos têm grades interativas; os editores têm áreas de texto; os visualizadores têm canvas; os experimentos têm estágios de execução.
- As cores de tema diferem por categoria (verde para ciência, roxo para jogos, âmbar para editores, rosa para design, ciano para cálculos, verde-claro para experimentos).
