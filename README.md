# ✦ RONYCODE — Plataforma de Aplicativos

Hub interativo de aplicativos web nas categorias **Estudos**, **Jogos**, **Úteis** e **Social**.

## 🚀 Como executar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173` no seu navegador.

## 🛠️ Tecnologias

- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide Icons**
- **PWA** (Progressive Web App com suporte offline)
